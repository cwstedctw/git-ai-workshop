看誰卡在個人版本循環、哪一組 PR 正等著補改或核准。只讀 GitHub 公開資料，不替學員操作。

無 token 時 GitHub API 每個 IP 每小時只有 60 次，只適合少量 repo 手動讀一次；自動更新必須先填 token。請使用唯讀、最小權限 token，且不要放進教材、repo 或截圖。

課前怎麼準備安全的 token

依 GitHub 官方步驟建立 fine-grained token；只選課堂練習 repo，Repository permissions 的 Contents、Metadata 與 Pull requests 都只給 Read-only，並設定短效期。這個雷達不需要任何寫入權限。
