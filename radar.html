設定（開場貼一次）

GitHub token 兩種建法擇一：classic token 不勾任何 scope（只能讀公開資源、額度 5,000 次／小時）；或 fine-grained 選「Public repositories (read-only)」。學員的工作坊 repo 與共用 repo 都建成公開（課堂全是模擬資料），一顆唯讀 token 就全讀得到。⚠️ 跨帳號讀取行為開課前務必用兩個真實學員帳號測通一次。token 設今天過期、只存在這個分頁的記憶體，關掉就消失——順便示範「token 不進版本控制」。
