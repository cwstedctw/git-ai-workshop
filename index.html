跟 AI 一起用 Git
——不背指令的版本控制

給大學教師的 2 小時動手工作坊

📘 教材——用讀的
兩階段全課路線、15 步觀念與完整操作、協作進階、故障排除與自然語言速查。上課看主線，課後卡住直接回來查。
課前請先做「行前準備包」。
🎮 闖關——用做的
課堂當天全程開這頁：15 步分成「自己的研究專案」與「研究生／指導教授協作」，可複製自然語言、查看 Git 儀表板並逐步驗收。請用 Chrome 或 Edge 開。
網址：cwstedctw.github.io/git-ai-workshop/quest.html

第一階段你會建立自己的公開假資料練習 repo；第二階段跟夥伴現場自建兩人的配對 repo。全站只用模擬資料，真正研究資料請依校內規範決定公開範圍。
