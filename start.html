跟 AI 一起用 Git｜不背指令的版本控制

開始之前：這條路長什麼樣

教材有點厚，直接點進去容易被淹沒。這一頁先讓你知道要走什麼路、要先準備什麼，以及哪幾步一定要你自己看過，不能交給 AI。課堂場與一個人自學走法不同，第貳段講清楚。

🔴 動手之前，兩條資料紅線

一、學生個資與未發表資料不進公開 repo——.gitignore 不是保密工具。二、私人 repo 也不放帳號密碼——提交過就進了歷史，事後刪檔沒用。

兩條的完整說明、監督三原則與「存錯了怎麼救」的急救箱，在 教材第伍章。

壹這是給誰的

給手上有研究專案的大學教師與研究生。判斷方式很簡單：資料夾裡出現過 論文v3_最終_真的最終.docx，或跟共同作者用附件改稿改到不確定哪份最新，這門課就是為你開的。

不必先會任何 Git 指令、終端機或程式語言。要有一台能上網的電腦、一個 GitHub 帳號、一個你慣用的 AI 助手。

這門課不教背指令，也不講 Git 內部原理；stash、rebase、fork 工作流、GitHub Actions 全部跳過。要練的是另一件事：當 agent 的指導教授，不是它的橡皮圖章。完整的「為什麼」在 教材第壹章。

貳兩種走法：你是哪一種

同一套 15 關，課堂場跟一個人自學走法不一樣。差別只在第二階段。

🅐 課堂場（工作坊）
現場有夥伴、有講師，跟著講師走完

15 關全走完。第一階段各自做自己的研究專案；第二階段兩人一組，一位當研究生、一位當指導教授，輪流提出修改與把關，最後交換角色再走一次短流程。

🅑 一個人自學
在家自己來、沒有夥伴

先只走第一階段 P1–P9。那本來就是你一個人的研究專案，走完就解決最痛的一半：版本回得去、東西備份在 GitHub、看得懂改了什麼。

⚠️ 第二階段需要兩個人，不能一個人假裝

C1–C6 練的就是「兩個人怎麼在同一份稿子上不打架」——提出、退回、補改、核准、合併。一個人做不出那個情境，等你找到共同作者、指導的學生，或參加正式場次再做。

請不要為了湊人數另外註冊一個 GitHub 帳號自己扮兩個角色。GitHub 服務條款寫明一人最多只能維持一個免費帳號，這不值得為了練習去踩。

參開始之前要先準備

⚠️ 行前準備是十項，不是三項

完整的十項一定要照 教材第貳章〈行前準備〉做完（含兩步驟驗證、裝 git 本體、裝 PowerShell 7、AI 助手授權設定、GitHub 登入……）。下面三條只是「你現在就能自我判斷有沒有走對方向」的最低門檻，不是完整清單。

三個最低門檻：① 裝好並登入你的 AI 助手（打得開、登入成功、找得到輸入框）；② GitHub 帳號能登入；③ 做一次「小試身手」——讓 AI 建一個小檔案，並請它回報 git 版本與 GitHub 帳號，然後你自己打開檔案來看。

第 ③ 項一句話就驗掉整條安裝鏈——它會回報 git 版本與 gh 帳號，裝沒裝 git、GitHub 有沒有登入，這一步就看得出來；而它本身就是這門課的第一課：AI 說做完了，不等於真的做完。⚠️ 但它驗不到兩步驟驗證（2FA）與 AI 助手的授權設定，那兩項只能照教材做。教材那邊有十項可勾選的互動清單、每一步的截圖與求救句，這裡不重複寫一份。請留兩個晚上，別排在開始前一天——有幾項要下載安裝，視網速可能要一小時以上。

伍我學會了嗎

走完第一階段之後，用這幾句話問自己。答得出來才算真的走過，闖關頁的進度條只是輔助。

  • 我知道 Git 管的是「一個資料夾」，而且講得出我現在在哪個資料夾。
  • 我能讓 AI 把一份修改存成一個版本，而且存之前我看過它改了哪幾行。
  • 我能把專案推上 GitHub，並在網頁上看到它。
  • 我看得懂歷史紀錄，能比較兩個版本差在哪裡。
  • 我知道「只是看看」「restore」「revert」是三種不同的回去，也知道哪一種在已經推出去之後才安全。
  • 我知道哪些檔案不該進版本庫，也知道 .gitignore 不是保密工具。
  • 我知道 agent 說「做完了」不等於做完，我會自己把檔案打開驗。
  • 我知道任何時候都可以喊停，也記得那句救援句怎麼說。

陸學完之後，下一步做什麼

  • 把一個真的研究專案搬進來。先判斷資料能不能公開；不確定就開私人 repo——但私人 repo 一樣不放帳密，敏感研究資料仍要依校內與計畫規範判斷。
  • 把常改的檔案換成純文字。筆記改 .md、論文改 .tex，逐行差異才看得到。
  • 找一位共同作者或你指導的學生，補走第二階段。兩個人一起做過一次 PR，之後真的協作才不會卡。
  • 如果你的期刊要求附上資料與程式，這套流程就是底層：完整的修改歷史、乾淨的檔案清單、說得清楚每一版差在哪。

動手前值得先看一次 教材第拾章〈三條誠實限制（不藏）〉：Word／Excel 看不到逐行差異、GitHub 方案功能會變、agent 會犯錯——先知道做不到什麼，才知道手上有什麼。
