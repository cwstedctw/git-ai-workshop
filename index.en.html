Using Git with AI
— version control without memorizing commands

A 2-hour hands-on workshop for university teachers

Git = a tool that remembers every change you make in a folder. The AI types all the commands; your job is to understand them and stay in charge. The AI assistant understands English (and most other languages) — talk to it in whatever language you think in.

🧭 Before you start — read this page first
What this path looks like: who it's for, how long it takes, what to prepare, the whole 15-step map, and which steps you have to check with your own eyes.
Learning on your own? Read the "Two routes" section first.
📘 The material — for reading
The full two-stage route, the ideas and complete operations behind all 15 steps, advanced collaboration, troubleshooting, and a plain-language phrase table. Follow the main line in class, and come straight back here whenever you get stuck afterwards.
Please work through the setup pack before class.
🗂️ The practice bench — walk it through with your mouse (5 minutes)
From a new file to a commit: move one file through a simulated working directory, staging area and repository into the history, and see what Git says at each step and which commands run behind it. No real Git is running, and a wrong click cannot break anything.
Do it once before class or before the hands-on steps; P3, P4, P6 and P8 will feel much easier.
🎮 The quest — for doing
Keep this page open throughout the workshop: the 15 steps, split into "your own research project" and "graduate student / advisor collaboration", with plain-language prompts you can copy, a Git dashboard, and step-by-step checks. Please open it in Chrome or Edge.
URL: cwstedctw.github.io/git-ai-workshop/quest.en.html

In Stage 1 you create your own public practice project (repo) filled with fake data; in Stage 2 you and a partner build a shared paired repo on the spot. Everything on this site uses simulated data only — for real research data, follow your institution's rules when you decide how public it may be.
